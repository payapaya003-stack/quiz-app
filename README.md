# 資格対策 暗記アプリ (PWA)

CSVを読み込んで使える、iPhone対応の一問一答アプリです。ビルド不要の静的サイト(HTML/JS/CSS のみ)です。

## GitHub Pages での公開手順
1. このフォルダの中身をすべて GitHub リポジトリのルートにアップロード(`index.html`, `sw.js`, `manifest.webmanifest`, `questions.csv`, `icons/`)
2. リポジトリの **Settings → Pages** で Branch: `main` / フォルダ: `/ (root)` を選んで保存
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone の **Safari** で開く
4. 共有ボタン → **ホーム画面に追加** → 以後はアプリとして起動(オフラインでも動作)

## 使い方
- ホームで **出題範囲**(全部 / 苦手のみ △× / 苦手+未評価)、**ジャンル(科目)**、**試験回**、**出題数** を選んで開始
- 選択肢をタップすると即座に正誤判定と解説を表示
- 解答後に **◎得意 / △微妙 / ×苦手** を任意で設定(もう一度押すと解除)。評価は端末に保存され、次回の「苦手のみ」出題に使われます
- 右上の **終了してスコア** でいつでも中断でき、解答済み分でスコアを集計(科目別・試験回別の正答率、間違えた問題の復習つき)

## 問題CSVの形式
列: `番号, 問題, 正答, 誤答１, 誤答２, 誤答３, 誤答４, 解説`(UTF-8。Shift_JIS も自動判別)

ジャンルは、問題文先頭のタグから自動判定します。
- `【R5後・問1】` → 科目: マーケティング / 試験回: R5後
- `【R5後・経営戦略 問1】` → 科目: 経営戦略 / 試験回: R5後

CSVに `ジャンル`(または `分野` / `科目`)列があれば、そちらを科目として優先します。

## 問題の差し替え
- アプリ内の「CSVを読み込む」で別のCSVを読み込めます(端末に保存)
- 同梱の問題自体を変える場合は `questions.csv` を置き換えてください。更新を確実に反映するには `sw.js` の `CACHE` の版数(`quiz-pwa-v1`)を上げてください

## 補足
- 苦手度・成績は端末の localStorage に保存されます(Safariのサイトデータを消去すると消えます)
- 問題の識別は問題文のハッシュで行うため、同じ問題文であれば別CSVでも苦手度が引き継がれます
